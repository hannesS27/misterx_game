🕵️ SPIELPRINZIP
1 Mister X läuft durch Böhringen und versteckt sich.
4 Teams (je mit Gruppenleiter) jagen ihn — jedes für sich.
8 Missionen (Stationen) sind im Ort verteilt. An jedem Ort ist ein 4-stelliger Code versteckt (Zettel/Kreide/Sticker).
Code gefunden → in der App eingeben → die Mission startet: Erste-Hilfe-Aufgabe + Handy-Challenge (Quiz/Minispiel). Zusammen ca. 5 Minuten pro Station.
Pro geschaffter Mission gibt der Spielleiter dem Team einen Standort von Mister X. Alle 8 → Standort alle 5 Minuten (Timer-Tab).
👤 ABLAUF FÜR GRUPPENLEITER
1. Datei am Handy öffnen → GRUPPE → Team wählen → die Story-Erklärung mit den Kids anschauen.
2. Missions-Ort anlaufen → Kids suchen den versteckten Code → eingeben.
3. Erste-Hilfe-Aufgabe machen → nur ihr tippt GESCHAFFT / NOCH NICHT.
4. Danach löst das Team die Handy-Challenge — sie bestätigt sich selbst.
5. Mission fertig → beim Spielleiter melden → Standort für das Team.
6. Lenkt euer Team so, dass möglichst alle Missionen gemacht werden und das Spiel nicht zu schnell endet.
⚠️ WICHTIG
Neuladen ist kein Problem — Fortschritt (auch innerhalb einer Mission) bleibt gespeichert.
Echte Verletzung/Notfall: Spiel stoppen, versorgen, Spielleiter anrufen — im Zweifel 112.
Spielabbruch (Wetter etc.): Spielleiter ruft alle Gruppenleiter an → alle zur Schule.
